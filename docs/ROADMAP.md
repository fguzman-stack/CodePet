# Roadmap

[Back to README](../README.md) · [Docs index](README.md)

## Shipped

- Virtual pet with stats, states, care actions and revival.
- Static coding challenges across 13 languages.
- Special algorithm challenges.
- Pomodoro study sessions with rewards.
- Debugging arcade, code review and hackathon systems.
- 12 visual themes plus animated backgrounds.
- Skill Tree, Season Pass, Weekly Missions, Moodlets and Pair Programming.
- Launcher widget.
- Spanish and English content.

## Current priorities

- Keep challenge counts and translations synchronized.
- Improve onboarding and screenshots as the UI evolves.
- Expand docs without growing the root README again.
- Add more tests around long-lived progression systems.

## Ideas

- Cloud sync.
- More advanced language tracks.
- More visual rewards and wardrobe items.
- Multiplayer or leaderboard features.
- Store distribution beyond GitHub Releases.
